# Agent Guide

pi-ext is a pi package that ships small, standalone pi extensions and
skills.

Before working here, read:

- `spec/docs/index.md` — the catalog of design documents and their reading
  order.
- `spec/skills/work.md` — the workflow to follow, including the
  documentation-sync rule.
- `spec/skills/task_tracking.md` — the `spec/docs/plan.md` record format
  and task selection rules.
- `spec/skills/report_tracking.md` — how session reports and their markers
  are written and reconciled.
- `spec/skills/adr_tracking.md` — when and how to record an architecture
  decision.

`spec/docs/` and `spec/skills/` are the authoritative starting points.
